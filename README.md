# Traffic_light_controller
Traffic light controller implemented using Vivado and Logisim

---

## Overview
This project implements a Finite State Machine (FSM) based traffic light controller for a four-way intersection. The controller cycles through Green, Yellow, and Red signals for each direction in a safe and timed sequence.

---

## Tools Used
- Vivado (Verilog coding and simulation)
- Logisim (Circuit design and validation)

---

## Features
- FSM-based design
- Four-direction traffic control
- Timed signal transitions
- Reset functionality
- Simulation verified
